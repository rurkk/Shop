# Пакетный импорт каталога KNITSEW

Импортёр запускается с рабочего Mac или Linux. Он использует API сотрудников и текущие правила Shop для фотографий, вариантов и публикации. Для каждой команды записи понадобятся рабочий email, код из письма и текущий код приложения-аутентификатора. Коды вводятся в терминале. Сессия хранится в памяти процесса.

## Подготовка таблицы

Распакуйте `catalog-photos-2026-11-14.zip`. В шаблоне `knitsew-catalog-import.xlsx` уже есть десять комплектов «Руси» и восемь кандидатов для галереи. Жёлтые ячейки предназначены для ввода. Ссылки и заметки по фото видны справа на листе «Товары».

- На листе «Товары» проверьте название, дизайн и тип изделия. У «Волка» тип оставлен пустым. Уточните его и поставьте «Да» в колонке «Импорт». Для парных футболок подтвердите, продаются ли они комплектом. Если продаются отдельно, внесите две строки с отдельными `slug`, фото и вариантами.
- На листе «Группы вариантов» заполните по строке на сочетание цвета и условий продажи. В одной строке можно перечислить размеры через запятую. Например, `M, L, XL`. Цену вводите числом в рублях. Срок в днях указывайте для статуса «Под заказ». Один код группы можно назначить нескольким товарам. SKU вычисляется из `slug`, размера и цвета. Для первоначального импорта черновиков группу можно оставить пустой.
- Сохраните постоянный `slug` после первого импорта. Колонка «Коллекция» принимает `slug` существующей коллекции. «Порядок» задаёт место товара в ней. Для фото используйте путь относительно папки `photos`. По порядку файлов `01-cover` станет обложкой, `02-detail` покажет вышивку крупным планом, следующие фото добавятся в галерею карточки.
- Перед отметкой «Публикация → Да» сверьте обложку, вышивку, цвета, цену, наличие и сроки в черновике. Для «Я не одна» нужен кадр, на котором нельзя опознать человека. Проверьте права на фотографии и изображения на изделиях по требованиям релиза. [Требования к витрине](requirements.md#главная-витрина)

## Установка и локальная проверка

Из корня репозитория. Нужен Python 3.11 или новее.

```sh
python3 -m venv "$HOME/.knitsew-catalog-import-venv"
"$HOME/.knitsew-catalog-import-venv/bin/python" -m pip install -r infra/ops/catalog-import-requirements.txt
```

Скопируйте [шаблон XLSX](../outputs/01a1d9f7-27c8-7902-8d51-b484e7384361/knitsew-catalog-import.xlsx) в корень репозитория под именем `knitsew-catalog-import.xlsx` и внесите правки. Сохраните структуру листов и заголовки. Проверка читает только локальные файлы и выводит ошибки с номерами строк.

```sh
"$HOME/.knitsew-catalog-import-venv/bin/python" infra/ops/catalog_import.py check \
  --workbook knitsew-catalog-import.xlsx \
  --photos catalog-photos-2026-11-14/photos
```

## Черновики на демо

Когда на `demo.knitsew.ru` заработает вход сотрудника, выполните команду. Она загружает выбранные фото, создаёт или обновляет черновики из журнала, добавляет варианты и размещает товары в коллекции. Ссылки на созданные черновики выводятся в терминал.

```sh
"$HOME/.knitsew-catalog-import-venv/bin/python" infra/ops/catalog_import.py import \
  --url https://demo.knitsew.ru \
  --workbook knitsew-catalog-import.xlsx \
  --photos catalog-photos-2026-11-14/photos \
  --state "$HOME/knitsew-import-demo.json"
```

Повторяйте команду с тем же журналом после обрыва или правок в таблице. Журнал хранит ID подтверждённых загрузок и карточек. Существующий `slug` без записи в журнале останавливает импорт, если карточку нельзя сопоставить с уже загруженными фото и данными черновика. Ошибка соединения на загрузке фото может оставить одну непривязанную копию в медиатеке, если Shop записал файл, а ответ потерялся до записи ID. По остальным подтверждённым загрузкам скрипт использует сохранённые ID.

Варианты, которые уже есть у черновика, можно дополнить новыми. Чтобы убрать ранее созданный вариант из продажи, задайте ему статус «Нет в наличии» в таблице или удалите его в админке и исключите из группы. Если товар нужно перенести в другую коллекцию, снимите старую привязку в админке. `import` пропускает опубликованные карточки. Для другого сервера нужен отдельный журнал.

## Публикация подтверждённых карточек

Выполните `import` после правок, затем отметьте «Публикация → Да» у проверенных карточек. Потребуется хотя бы один вариант у каждого товара и опубликованная коллекция. `publish` заранее сверяет выбранные карточки с таблицей и проверяет их доступность через публичный API после публикации. На новом контуре отдельно опубликуйте витрину с заголовком и баннером в `/admin/storefront`. Товары для стартового экрана добавляются в «Выбор команды» через управление каталогами.

```sh
"$HOME/.knitsew-catalog-import-venv/bin/python" infra/ops/catalog_import.py publish \
  --url https://demo.knitsew.ru \
  --workbook knitsew-catalog-import.xlsx \
  --photos catalog-photos-2026-11-14/photos \
  --state "$HOME/knitsew-import-demo.json"
```

Каждая карточка публикуется отдельным запросом. Если прервётся связь, запустите ту же команду с тем же журналом. Карточки, уже опубликованные с теми же данными, пройдут проверку повторно.

## Примеры вышивки по фото

На листе «Галерея» отметьте «Добавить → Да» у нужных примеров. Если есть согласованное исходное фото для сравнения, положите его в `photos` и укажите относительный путь. Всего в галерее может быть 24 работы. Команда добавляет выбранные примеры в конец существующего списка. На опубликованной витрине они появятся сразу.

```sh
"$HOME/.knitsew-catalog-import-venv/bin/python" infra/ops/catalog_import.py gallery \
  --url https://demo.knitsew.ru \
  --workbook knitsew-catalog-import.xlsx \
  --photos catalog-photos-2026-11-14/photos \
  --state "$HOME/knitsew-import-demo.json"
```

Для внесения того же набора на другой контур подставьте его HTTPS-адрес и новый путь к журналу. Начните с команды `import`, чтобы просмотреть черновики на целевом контуре перед публикацией.

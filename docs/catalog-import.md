# Полный импорт витрины KNITSEW

Команда `import` читает XLSX и папку `photos` и через API сотрудников обновляет коллекции, товары и главную. В демонстрационном пакете собраны 10 товаров «Руси», четыре карточки с локального стенда, баннер, два примера вышивки и подсказки о цене, сроках и доставке. Пакет размещает 14 товаров в «Руси» и четыре из них в «Выборе команды».

## Подготовка пакета

Для запуска из репозитория используйте [готовый XLSX](../outputs/01a1d9f7-27c8-7902-8d51-b484e7384361/knitsew-catalog-import.xlsx) и папку `catalog-photos-2026-11-14/photos`. [ZIP с данными](../catalog-photos-2026-11-14.zip) содержит тот же XLSX и все фотографии. При использовании распакованного пакета укажите его пути в `--workbook` и `--photos`.

- **Товары.** «Импорт → Да» включает карточку в обновление. «Публикация → Да» показывает её в опубликованных коллекциях. Для размещения в нескольких подборках перечислите `slug` через запятую. «Порядок» применяется в каждой из указанных подборок. Сохраняйте `slug` товара при обновлении.
- **Коллекции.** Укажите `slug`, название, тип, порядок и публикацию. Описание и путь к обложке можно оставить пустыми. Чтобы скрыть коллекцию, поставьте «Публикация → Нет» в её строке.
- **Группы вариантов.** Строка задаёт цвет, размеры, цену, наличие и срок изготовления. Для статуса «Под заказ» срок обязателен. Размеры можно перечислить через запятую. При пустой колонке SKU он вычисляется из `slug` товара, размера и цвета. Явный SKU указывают для одного размера. В демонстрационных карточках сохранены SKU с локального стенда.
- **Замеры.** Укажите фактическую ширину и длину изделия для каждого размера. Длина рукава необязательна. Демонстрационные замеры «Воли» перенесены с локального стенда. Замеры десяти товаров «Руси» пока пустые.
- **Витрина.** Заполните одну строку с настройками главной. Для публикации нужны заголовок и баннер. Подсказки о цене, сроке и доставке можно задать текстом.
- **Галерея.** Витрина покажет выбранные строки «Да» в порядке таблицы. Исходник для сравнения необязателен. Поддерживается до 24 примеров.

Указывайте пути к фото относительно `photos`. Для карточки с фото изделия используйте `01-cover` и `02-detail`. Для студийной обложки используйте `01-studio`, `02-original` и `03-detail`. Дополнительные кадры обозначьте номером и `alternate`. В карточке допустимо до 12 фото. Перед публикацией нового контента проверьте права на фотографии и данные моделей. [Требования к витрине](requirements.md#главная-витрина)

## Запуск и повторное обновление

Нужен Python 3.11 или новее. Установите зависимости из корня репозитория.

```sh
python3 -m venv "$HOME/.knitsew-catalog-import-venv"
"$HOME/.knitsew-catalog-import-venv/bin/python" -m pip install -r infra/ops/catalog-import-requirements.txt
```

Проверьте состав пакета. Команда `check` читает таблицу и изображения, проверяет ссылки между листами и показывает ошибки с номерами строк.

```sh
"$HOME/.knitsew-catalog-import-venv/bin/python" infra/ops/catalog_import.py check \
  --workbook outputs/01a1d9f7-27c8-7902-8d51-b484e7384361/knitsew-catalog-import.xlsx \
  --photos catalog-photos-2026-11-14/photos
```

Укажите адрес нужного контура и его журнал. Для входа потребуются email сотрудника, код из письма и код из приложения-аутентификатора. Коды вводятся в терминале.

```sh
"$HOME/.knitsew-catalog-import-venv/bin/python" infra/ops/catalog_import.py import \
  --url https://demo.knitsew.ru \
  --workbook outputs/01a1d9f7-27c8-7902-8d51-b484e7384361/knitsew-catalog-import.xlsx \
  --photos catalog-photos-2026-11-14/photos \
  --state outputs/01a1d9f7-27c8-7902-8d51-b484e7384361/knitsew-import-demo.json
```

Для `--state` подставьте путь к журналу предыдущего импорта на этот адрес. В примере указан журнал первого импорта на демо. Сохраните его вне Git. После правок в пакете или обрыва связи повторите ту же команду с тем же журналом. Для каждого контура используйте отдельный журнал и запускайте один импорт за раз.

Команда обновляет опубликованные карточки по `slug` и сохраняет их ID. Списки фото, вариантов, замеров и примеров в галерее заменяются данными из таблицы. Пустой список замеров очищает прежние замеры. Если карточка из журнала исключена из импорта или из таблицы, команда снимает её с публикации и убирает из перечисленных в пакете коллекций. Заказы сохраняют зафиксированные при оформлении данные.

Журнал сохраняет подтверждённые загрузки и ID товаров. Повтор с тем же содержимым переиспользует изображения и сверяет опубликованный результат. Обновление выполняется последовательностью запросов. При обрыве после загрузки фото и до записи его ID в журнале в медиатеке может остаться непривязанная копия. Повтор продолжает обновление по фактическому состоянию сервера.

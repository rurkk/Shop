# Пакетный импорт каталога KNITSEW

Импортёр запускается с рабочего Mac или Linux. Он использует API сотрудников и текущие правила Shop для фотографий, вариантов и публикации. Для каждой команды записи понадобятся рабочий email, код из письма и текущий код приложения-аутентификатора. Коды вводятся в терминале. Сессия хранится в памяти процесса.

## Подготовка таблицы

Распакуйте `catalog-photos-2026-11-14.zip`. В `knitsew-catalog-import.xlsx` заполнены десять карточек «Руси». У всех стоит «Да» в колонках «Импорт» и «Публикация». Справа на листе «Товары» указаны источники и заметки по фотографиям. Жёлтые ячейки можно редактировать.

- На листе «Товары» указаны названия, типы изделий, формат вышивки, описания и группы вариантов. Формат вышивки выбран по фото. На стенде «Волк» указан как футболка. Парные модели продаются комплектами из двух футболок одного размера.
- На листе «Группы вариантов» одна строка задаёт сочетание цвета и условий продажи. Размеры перечисляются через запятую. Цены в рублях рассчитаны по прайсу менеджера. Для стенда указаны размеры S–XL и статус «Под заказ». Система принимает срок одним числом, поэтому в вариантах стоит 14 дней, а в описании указан диапазон 5–14 дней. Один код группы можно назначить нескольким товарам. SKU вычисляется из `slug`, размера и цвета.
- На листе «Замеры» можно указать ширину и длину изделия по размерам, а для моделей с длинным рукавом также длину рукава. Укажите `slug` товара и размер. Эти строки используются в таблице размеров на витрине. В пакете замеры оставлены пустыми до получения данных от производства. При обновлении черновика заполненные строки для товара заменяют набор его замеров, а пустой лист сохраняет уже внесённые в админке замеры.
- Сохраните постоянный `slug` после первого импорта. Колонка «Коллекция» принимает `slug` существующей коллекции. «Порядок» задаёт место товара в ней. Укажите путь к фотографиям относительно папки `photos`. Для студийной обложки назовите первые файлы `01-studio`, `02-original` и `03-detail`. `02-original` содержит прежнее фото изделия, а `03-detail` показывает вышивку крупным планом. Для карточек с фото на обложке используйте `01-cover` и `02-detail`. У дополнительных кадров укажите номер и `alternate`, например `04-alternate.jpg`.
- Для публикации каждой карточке нужны описание и хотя бы один вариант. Целевая коллекция должна быть опубликована. Перед переносом на рабочую витрину сверьте фактические размеры, цены и права на фотографии и изображения на изделиях. [Требования к витрине](requirements.md#главная-витрина)

## Установка и локальная проверка

Из корня репозитория. Нужен Python 3.11 или новее.

```sh
python3 -m venv "$HOME/.knitsew-catalog-import-venv"
"$HOME/.knitsew-catalog-import-venv/bin/python" -m pip install -r infra/ops/catalog-import-requirements.txt
```

Скопируйте [заполненный XLSX](../outputs/01a1d9f7-27c8-7902-8d51-b484e7384361/knitsew-catalog-import.xlsx) в корень репозитория под именем `knitsew-catalog-import.xlsx`. При редактировании сохраните структуру листов и заголовки. Проверка читает локальные файлы и выводит ошибки с номерами строк.

```sh
"$HOME/.knitsew-catalog-import-venv/bin/python" infra/ops/catalog_import.py check \
  --workbook knitsew-catalog-import.xlsx \
  --photos catalog-photos-2026-11-14/photos
```

## Импорт с публикацией

Подставьте адрес нужного контура. Команда загрузит фотографии, заполнит карточки и варианты, разместит товары в коллекции и сверит данные с таблицей. Карточки с отметкой «Публикация → Да» появятся в коллекции за один запуск. Импортёр проверит их доступность через публичный API. Для импорта черновиков установите «Публикация → Нет».

```sh
"$HOME/.knitsew-catalog-import-venv/bin/python" infra/ops/catalog_import.py import \
  --url https://demo.knitsew.ru \
  --workbook knitsew-catalog-import.xlsx \
  --photos catalog-photos-2026-11-14/photos \
  --state "$HOME/knitsew-import-demo.json"
```

Повторяйте команду с тем же журналом после обрыва или правок в таблице. Журнал хранит ID подтверждённых загрузок и карточек. Существующий `slug` без записи в журнале останавливает импорт, если карточку нельзя сопоставить с уже загруженными фото и данными черновика. Ошибка соединения на загрузке фото может оставить одну непривязанную копию в медиатеке, если Shop записал файл, а ответ потерялся до записи ID. По остальным подтверждённым загрузкам скрипт использует сохранённые ID.

Варианты черновика можно обновлять и дополнять. Чтобы убрать вариант из продажи, задайте ему статус «Нет в наличии» или удалите его в админке и исключите из группы. При переносе между коллекциями управляйте старыми привязками в админке. Опубликованные карточки с отметкой «Да» при повторном импорте проходят сверку. Чтобы обновить их из таблицы, сначала снимите их с публикации в админке. Для другого сервера нужен отдельный журнал.

Покупатели увидят товары в соответствующей коллекции. Стартовой подборкой «Выбор команды» управляют в админке каталогов. Баннер витрины на новом контуре публикуется в `/admin/storefront`.

## Обновление фото в существующих карточках

Чтобы добавить студийные обложки в уже импортированные карточки, выполните `photos` с тем же журналом. Команда загружает новые файлы и сверяет порядок фотографий на витрине. Карточка может оставаться опубликованной. Существующие фотографии должны входить в новый пакет и быть учтены в журнале.

```sh
"$HOME/.knitsew-catalog-import-venv/bin/python" infra/ops/catalog_import.py photos \
  --url https://demo.knitsew.ru \
  --workbook knitsew-catalog-import.xlsx \
  --photos catalog-photos-2026-11-14/photos \
  --state "$HOME/knitsew-import-demo.json"
```

## Отдельная публикация готовых черновиков

Если карточки уже созданы из этой таблицы, можно отметить у них «Публикация → Да» и запустить `publish` с тем же журналом. Команда сверит подготовленные карточки с таблицей и опубликует их.

```sh
"$HOME/.knitsew-catalog-import-venv/bin/python" infra/ops/catalog_import.py publish \
  --url https://demo.knitsew.ru \
  --workbook knitsew-catalog-import.xlsx \
  --photos catalog-photos-2026-11-14/photos \
  --state "$HOME/knitsew-import-demo.json"
```

Каждая карточка публикуется отдельным запросом. После обрыва связи повторите команду с тем же журналом, чтобы продолжить с сохранённого состояния.

## Примеры вышивки по фото

На листе «Галерея» отметьте «Добавить → Да» у нужных примеров. Если есть согласованное исходное фото для сравнения, положите его в `photos` и укажите относительный путь. Всего в галерее может быть 24 работы. Команда добавляет выбранные примеры в конец существующего списка. На опубликованной витрине они появятся сразу.

```sh
"$HOME/.knitsew-catalog-import-venv/bin/python" infra/ops/catalog_import.py gallery \
  --url https://demo.knitsew.ru \
  --workbook knitsew-catalog-import.xlsx \
  --photos catalog-photos-2026-11-14/photos \
  --state "$HOME/knitsew-import-demo.json"
```

Для импорта на другой контур подставьте его HTTPS-адрес и новый путь к журналу.
